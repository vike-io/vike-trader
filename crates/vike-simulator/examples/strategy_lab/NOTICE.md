# Notice

The strategies in this folder are hand-written Rust reimplementations of the trading rules of scripts in the PineForge
Validation Corpus. Those whose licence permits it moved to the shipped strategy files (the repository root's `strategies/`,
whose `NOTICE` covers them), and the lab runs them from there; the four the gallery did not take were deleted (2026-11-10), so
this folder's `strategies/` holds no rule file now. They are changed from the originals: rewritten in another language, against vike's own engine and
indicators. No code generated from the originals was read or used. The reference trade lists and bars they were checked
against are not part of this folder.
